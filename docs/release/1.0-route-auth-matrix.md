# TableTop DM 1.0 Route/Auth Matrix

Status: release-gate policy matrix for the local 1.0 track.

This matrix defines the minimum route policy that must be true before 1.0. A route may be stricter than listed here, but it must not be wider.

## 1.0 Blockers

- Any player route that returns DM-only state without a principal-scoped filter.
- Any realtime scoped event delivered through the raw campaign room.
- Any player ability to use `as_principal_id` or another supplied principal id to widen access.
- Any save/load roundtrip that drops ledger `visible_to`, principal membership, or player-state viability.
- Any startup path that cannot reach `/readyz?verbose=1` without manual environment repair.

## Current Local-Demo Exception

Some local GUI and control-plane routes still allow anonymous access because TableTop DM is currently a local desktop app. Phase 43 keeps that local-demo posture but documents it explicitly; product-grade invite tokens and DM protection are required before calling the identity surface 1.0-complete.
