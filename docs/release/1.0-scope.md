# TableTop DM 1.0 Scope

Status: scope freeze for the 1.0 release-candidate track.

## 1.0 Definition

Version 1.0 means a local DM can install TableTop DM, create or load a campaign, manage players, run a session, have players join, move, chat, fight, see only authorized state, save/load, recover from restart, and diagnose setup failures without reading source code.

1.0 does not mean every planned simulation feature is complete. It means the core gameplay loop is safe, understandable, and recoverable.

## Release Rules

- No new broad feature work enters 1.0 unless it closes a blocker or critical release gap.
- All state-changing gameplay remains proposal -> validation -> auth/resource check -> tool call -> state delta -> ledger event -> scoped broadcast.
- LLMs may propose, narrate, extract, and cite. They do not mutate canonical state directly.
- Player-facing reads must come from principal-scoped APIs, especially `player_state`.
- UI hiding is not security. API filtering and data-layer visibility are the release boundary.
- RAG reranking, advanced chunk UI polish, extra map themes, and transcript/audio intake are post-1.0 unless a blocker forces a narrow fix.

## In Scope

| Area | 1.0 contract |
|---|---|
| Local install / launcher | Windows shortcut and documented manual boot start dependencies, app, readiness, and dashboard. |
| Campaign lifecycle | Create, resume, pause/end/archive where supported, and inspect campaigns from the GUI. |
| Session lifecycle | Create/resume active sessions, preserve story state, and expose session-bound player state. |
| Principal identity | Local principal model, campaign membership, session join, and scoped socket room joins. |
| Player state | `GET /api/sessions/<id>/player_state` is the canonical player runtime read model. |
| Visibility | Ledger reads, continuity APIs, recaps, player state, and WebSocket delivery enforce visibility. |
| Maps and movement | Map renderer, current-map tracking, movement proposals, POI discovery, and spatial event scope. |
| Combat basics | Initiative, active turn, legal action hints, attack/end-turn loop, and NPC turn advance. |
| Chat and narration | Player/NPC chat path, DM narration, visibility-safe ledger events. |
| Story State Board | Location, game time, active NPCs/quests, plot threads, resources, DM notes. |
| RAG baseline | Upload, store, retrieve, visibility filter, evidence/citation surfaces. |
| Session Intel | Extract, queue, review, approve/edit/reject, apply, recaps, continuity. |
| Save/load | Encrypted game/program saves, passphrase handling, import/export, principal remap. |
| Health/readiness | `/health`, structured `/readyz`, preflight diagnostics, clean E2E skip/fail behavior. |
| Documentation | Quickstart, DM/player/control-plane/save-load/troubleshooting/security/release docs match shipped behavior. |

## Post-1.0

| Area | Reason |
|---|---|
| RAG reranker | Quality improvement, not core release safety. |
| Advanced per-chunk visibility UI polish | Valuable, but baseline retrieval visibility already exists; only release-blocking leak fixes stay in scope. |
| Transcript/audio intake | Adds ambiguity and volume; depends on stable identity, snapshot/delta, and review flows. |
| Advanced economy/divine/faction tuning | Simulation depth after core playability. |
| Procedural art polish and extra map themes | Presentation improvement after release gate. |
| Public multiplayer auth provider | Local identity is the 1.0 target; OAuth/hosted multiplayer is later. |
| Campaign marketplace/import ecosystem | Beyond local release-candidate contract. |

## Known Release Risks

- Local identity is still too soft for 1.0 until player join codes and DM protection are productized.
- Snapshot and WebSocket deltas need explicit cursor-gap recovery before release.
- Route auth is not yet declared in one complete matrix.
- Save/load needs adversarial tests for passphrase, replace, remap, RAG, ledger visibility, and player-state after import.
- Docs still need a full reality pass across README, wiki, security, troubleshooting, and API references.
