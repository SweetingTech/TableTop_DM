## Golden Path Acceptance

The 1.0 golden-path E2E must prove:

1. Clean stack boots.
2. Dashboard opens.
3. DM creates or selects a campaign.
4. Session exists and player can join.
5. `/game` loads `player_state`.
6. Player moves on map and sees a scoped update.
7. Player discovers visible POI.
8. Chat creates visible event.
9. Combat action and turn advance work.
10. DM-only state never appears in player UI.
11. Save/export works.
12. Restart/resume returns equivalent player-visible state.

## Failure Artifacts

E2E and RC scripts should preserve, at minimum:

- `test-results-e2e/e2e-readyz.json`
- `test-results-e2e/e2e-root-response.html`
- browser screenshots/videos/traces on failure
- server log for the live test app
- route response payload for failed auth/visibility tests
