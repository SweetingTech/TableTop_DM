Program Save

                        

                            Installation-wide configuration: API keys (OpenRouter / OpenAI / etc.), default
                            image-gen model, the LocalPlayer principal. Export once, import on a new machine to
                            restore your setup. Encrypted — you'll need the same passphrase to
                            load it again. Save it outside Docker (Desktop, USB, your password manager — wherever
                            you keep portable credentials).
                        

                        

                            
                            
                            
                        

                        

                    


                    

                        
Game Save (current campaign)

                        

                            Everything tied to (no campaign selected):
                            maps, entities, POIs, decorations, sessions, ledger events. Carry a campaign between
                            machines — or just keep a backup before you do something risky. Encrypted.
